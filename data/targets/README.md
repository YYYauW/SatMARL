# Fixed algorithm-agnostic task catalogs

`train_requests.csv` and `test_requests.csv` each contain 3,072 fully specified
point-observation requests. They are generated by:

```bash
python scripts/generate_task_catalogs.py \
  --output-dir data/targets \
  --train-count 3072 --test-count 3072 \
  --train-seed 2701 --test-seed 2702 \
  --max-steps 240 \
  --minimum-separation-deg 0.2
```

The spatial design places one jittered sample in every cell of a 48×64
equal-area `sin(latitude)-longitude` grid. It is not conditioned on satellite
ground tracks. Task modes, cooperation types, priorities, time windows, data
volumes, and resource requirements are fixed in the CSV files, so every
algorithm sees the same workload.

`catalog_manifest.json` records the exact seeds, quotas, distribution
statistics, minimum within/cross-split angular separation, and SHA256 hashes.
The train and test coordinates have zero exact overlap.

With the Walker-Delta 64/8/1 constellation at 550 km, the raw geometry audit
found 97,306 visible satellite-target steps for training and 96,943 for test,
a difference of 0.37%. At reset with the same environment seed, the full
constraint mask exposed 76 train versus 69 test task actions across 33 versus
31 active satellites. These figures are diagnostics, not learned-policy
results.

This benchmark is geographically uniform and algorithm-agnostic. It is not a
model of real population, disaster, cloud, or commercial-demand intensity.

## Mixed point/area benchmark

`area_train_requests.csv` and `area_test_requests.csv` use independent seeds
and contain 3,072 requests each: 768 point requests and 2,304 continuous,
oriented rectangular area requests. Small, medium, and large area requests
have equal quotas. Their orientation is stratified over 0--360 degrees.

The CSV deliberately stores `cooperation_mode=auto` for area requests. The
environment derives the required strip count and minimum contributing
satellites from area dimensions and compatible payload feasibility. The
low-discrepancy coverage samples are only a numerical union estimator; policy
actions remain continuous directed strip polygons following satellite ground
track direction.

`area_catalog_manifest.json` records the distribution and SHA256 hashes.
